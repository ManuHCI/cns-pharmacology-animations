# CNS Pharmacology Animations

Interactive, browser-based animations for teaching CNS Pharmacology to MBBS and MD Pharmacology students. Each animation is a single, self-contained HTML file, no installation, no dependencies. Open in any modern browser, or project directly in a lecture hall.

**Live site:** https://manuhci.github.io/cns-pharmacology-animations/

Developed at the Department of Pharmacology, Maulana Azad Medical College & Lok Nayak Hospital, New Delhi, for use in classroom teaching and as a free open educational resource.

## How to use

- **In a lecture:** open the live link on the classroom computer, full-screen the browser (F11). Visuals are designed for projector-friendly contrast and large text.
- **Offline / no internet:** download the repository as a ZIP (green "Code" button on GitHub → Download ZIP). Every animation works offline once downloaded.
- **For your own course:** fork the repository or download the files. You are free to adapt them under the license terms below.

## Audience

- MBBS undergraduates (clinical pharmacology lectures)
- MD Pharmacology residents (mechanism deep-dives)
- Pharmacy and nursing students
- Self-study learners preparing for entrance and licensing exams

## How to contribute

Suggestions, corrections, and pull requests are welcome. If you spot a pharmacological inaccuracy, open an Issue with a citation and I'll fix it. If you would like to contribute an animation for another CNS topic, please open an Issue first to discuss scope and style.
